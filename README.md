# app_camera_web.dart

Helper for accessing the Camera and scanning QR code for the web (including Flutter Web)

* [`camera_web`](camera_web) Camera Media Web abstraction
* [`js_qr`](js_qr) Dart Cozmo jsQR wrapper
* [`qrscan_flutter_web`](qrscan_flutter_web) Flutter web qrcode scanner
* [`qrscan_flutter`](qrscan_flutter) the QR code scan service contract
* [`qrscan_flutter_mobile_scanner`](qrscan_flutter_mobile_scanner) Flutter QR code scanner (Android, iOS, macOS, web) using the [mobile_scanner](https://pub.dev/packages/mobile_scanner) package

Web demo:
* https://qrscan-example.surge.sh/
